## 产品发布/更新

### Apple 智能千问扩展现身 Mac 简体中文支持文档

苹果 Mac 简体中文使用手册新增“在 Mac 上配合 Apple 智能使用千问”页面，说明中国大陆用户可让写作工具与 Siri 调用千问能力。IT之家报道，该扩展面向 macOS 26.6 或更高版本，并需要符合地区、账户和设备条件；功能是否已经向所有用户开放，仍应以设备上的实际入口和苹果后续说明为准。

🔗 [IT之家](https://www.ithome.com/0/987/366.htm) ｜ [Apple 支持](https://support.apple.com/zh-cn/guide/mac-help/mchl46b3ab20/mac)

### ChatGPT 桌面端加入语音交互，可用语音发起多步骤任务

据 IT之家报道，OpenAI 为 ChatGPT 桌面应用加入语音交互，用户可通过语音向智能体下达任务，并在 macOS 上结合屏幕内容完成多步骤操作。报道还提到 ChatGPT Voice、ChatGPT Work 与 Codex 的衔接；由于暂未找到对应的一手发布说明，具体模型名称、平台范围、权限边界与分批开放节奏仍应以 OpenAI 客户端实际状态为准。

🔗 [IT之家](https://www.ithome.com/0/987/452.htm)

### Grok Imagine 支持悬停选择局部并即时编辑图像

Elon Musk 转发的演示显示，Grok Imagine 图像编辑可以把光标悬停到画面特定区域，再直接提出局部修改要求。相比整图重绘，局部选择有助于保留人物、构图和其他未选区域；但演示没有给出复杂遮挡、边缘融合或多轮编辑的一致性数据，实际效果仍需按素材测试。

🔗 [X：Elon Musk (@elonmusk)](https://x.com/elonmusk/status/2086127247077843282)

### Claude Code v2.1.225 增加网关支出限额与工作区信任提示

Claude Code v2.1.225 为网关用量警告加入支出上限、重置时间和操作者消息，并在代理进入未受信任目录时显示工作区信任提示。该版本还修复了 macOS 上部分 MCP OAuth 服务器间歇性返回 401、跨会话消息滞留，以及 Remote Control 会话恢复后历史记录损坏等问题。

🔗 [GitHub：Anthropic Claude Code Releases](https://github.com/anthropics/claude-code/releases/tag/v2.1.225)

## 行业动态

### Cloudflare 称非人类流量已超过人类流量，预计差距继续扩大

据 IT之家对 Cloudflare 2026 年第二季度财报电话会的整理，AI 机器人等非人类流量在 5 月已超过人类流量，公司预计两者差距未来数年还会迅速扩大。这里的“非人类流量”并不等同于全部由生成式 AI 产生，也包含搜索爬虫、自动化服务与恶意机器人等不同类型；“五年后达到 1000 倍”属于管理层趋势预测，不是已经发生的流量事实。

🔗 [IT之家](https://www.ithome.com/0/987/438.htm)

### Firebird 在亚美尼亚启动大型 AI 工厂

Firebird 在亚美尼亚启动面向区域市场的 AI 工厂，采用 NVIDIA 加速计算与 Dell Technologies 基础设施。NVIDIA 将其称为独联体地区规模最大的同类项目，并介绍了 Blackwell、Rubin 与 DSX 等技术路线；项目的真实算力规模、投产节奏与客户使用情况，还需随着后续建设和运营数据继续观察。

🔗 [NVIDIA Blog](https://blogs.nvidia.com/blog/firebird-ai-factory-armenia-blackwell-rubin-dsx)
